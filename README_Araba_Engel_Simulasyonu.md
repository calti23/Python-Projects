# Araba Engel Simülasyonu

Bu proje, bir arabanın engellere karşı nasıl yönlendirilebileceğini ve sensör/tespit mantığını simüle eden bir Python uygulamasıdır.

## Dosya

- [Araba Engel Simülasyonu.zip](Araba%20Engel%20Sim%C3%BClasyonu.zip)

## Proje Hakkında

Bu içerik, engel algılama ve araç hareket kontrolü temelli örnek bir simülasyon yapısını içerir. Projede genellikle şu bileşenler yer alır:

- Araba/araç hareket modeli
- Engellere karşı sensör veya mesafe analizi
- Basit karar mekanizması
- Görsel veya terminal tabanlı simülasyon çıktısı

## Gerekli Araçlar

- Python 3.8+
- Görsel arayüz/grafik kütüphaneleri (projenin içindeki dosya yapısına göre değişebilir)
- Gerekirse `matplotlib`, `numpy`, `pandas` gibi paketler

## Çalıştırma

1. Zip dosyasını bilgisayarınıza indirin.
2. Zip içeriğini çıkarın.
3. Çıkan klasöre gidin.
4. Python dosyasını çalıştırın:

```bash
python "dosya_adi.py"
```

## Not

Projede dosya adları Türkçe karakter ve boşluklar içerebileceğinden, komut satırında çalıştırırken dosya adını tırnak içinde kullanmanız önerilir.
