# Araba Engel Simülasyonu LidarMode

Bu proje, Lidar destekli bir araba engel simülasyonu örneğini içerir. Standart versiyondan farklı olarak sensör verisi ve engel tespiti mekanizması Lidar tabanlı şekilde modellenmiştir.

## Dosya

- [Araba Engel Simülasyonu LidarMode.zip](Araba%20Engel%20Sim%C3%BClasyonu%20LidarMode.zip)

## Proje Hakkında

Bu içerik, engel algılama ve araç yönlendirme mantığının Lidar benzeri mesafe tarama yaklaşımıyla işlendiği bir örnektir. Çoğunlukla şu unsurları içerir:

- Mesafe tarama / Lidar benzeri sensör verisi
- Engel algılama ve güvenli mesafe kontrolü
- Yönlendirme kararları
- Görsel veya simülasyon çıktısı

## Gerekli Araçlar

- Python 3.8+
- `numpy`, `matplotlib` veya benzeri destekleyici kütüphaneler
- Proje içindeki kod yapısına göre ek bağımlılıklar gerekebilir

## Çalıştırma

1. Zip dosyasını indirin.
2. İçeriği çıkarın.
3. Çıkan klasördeki Python dosyasını çalıştırın:

```bash
python "dosya_adi.py"
```

## Not

Dosya adlarında boşluk ve Türkçe karakter bulunduğundan, terminalde çalıştırırken dosya adını mutlaka tırnak içine almanız önerilir.
