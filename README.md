# Python Projeleri

Cointains Project Created With Python Language

## Gereksinimler

Aşağıdaki paketler örnekleri çalıştırmak için genelde yeterlidir. Dosyalar içinde farklı/ek paket gereksinimleri belirtildiyse onlara uyun.

- Python 3.8+
- pandas
- numpy
- matplotlib
- seaborn
- plotly
- scikit-learn (anomali tespiti örnekleri için)

Genelde şu komut ile kurulum yapılır:

pip install pandas numpy matplotlib seaborn plotly scikit-learn

## Nasıl çalıştırılır

Her bir örnek bağımsızdır. Terminal/komut satırından dosyanın bulunduğu dizine gidip aşağıdaki şekilde çalıştırabilirsiniz:

python "Dosya Adı.py"

Not: Dosya adlarında Türkçe karakter ve boşluklar olduğu için isimleri tırnak içinde vermeniz veya dosya adlarını terminale yapıştırırken dikkatli olmanız gerekir.
